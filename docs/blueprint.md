# **App Name**: BIBI.track Mobile

## Core Features:

- User Authentication: Implement user authentication via Firebase, using company code, login, and password to access the application.
- PWA Integration: Display the existing BIBI.track PWA within a WebView component, injecting the user's unique ID into the PWA context for seamless integration.
- Location Tracking Service: Implement background location tracking and synchronization with Traccar via Firebase Cloud Functions. Location data will be collected periodically and synced to the Traccar server.

## Style Guidelines:

- Use the existing BIBI.track PWA color scheme.
- A vibrant teal (#7d5abe) to highlight key actions and elements.
- Maintain the current typography to ensure brand consistency.
- Use Material Design icons to ensure a modern and consistent look.
- Employ a clean and intuitive layout, prioritizing ease of navigation.
